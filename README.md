# Ray Tracing — "Le Voyage de Chihiro" (Sixième Station)

CPU ray tracer in **C** with **SDL2** output.

## Build / Run

This Makefile tries `sdl2-config`, then `pkg-config` (MSYS2 / Unix-like environment).

### Windows (PowerShell)

```powershell
.\build.ps1
.\run.ps1
```

```bash
make
make run
```
